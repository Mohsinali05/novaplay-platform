# NovaPlay Independent Platform v2

An independent game platform starter with a Super Admin control center, partner API credentials, game catalog, and original game prototypes.

## Start on Windows
1. Extract the ZIP to a normal folder such as `Documents\NovaPlay`.
2. Install Node.js LTS (Node 20 or newer; the app uses only Node built-ins).
3. Double-click `START-NOVAPLAY.bat`.
4. Keep the black server window open. Your browser opens at `http://localhost:3000`.

## First admin login
- Username: `admin`
- Password: `ChangeThisPassword123!`

Change these before exposing the server to any network. Configure `.env` using `.env.example`.

## Included
- Super Admin login and overview
- Partner creation, API key display-once, activate/suspend controls
- Partner API catalog and session launch
- Nova Slots, Nova Roulette, Nova Blackjack, Nova Orbit prototypes
- Activity view for sessions and score submissions
- JSON file persistence in `data/store.json`

## Sandbox restrictions
All game balances are virtual demo points only. This project does not process deposits, withdrawals, cash wagers, cash prizes, or real-money gaming. Do not connect payment rails or enable real-money play without qualified legal advice, required licences, jurisdictional approvals, age/identity controls, responsible-gaming controls, security review and approved payment-provider arrangements.

## Partner API
See `API.md`. Partner keys are generated by Super Admin and sent using `X-API-Key`.

## Production work still required
Use a production database, secure secret management, password hashing and MFA, rate limiting, audit logs, backups, TLS, monitoring, penetration testing, regulatory review, and deployment hardening before production use. The built-in JSON store is for local development only.


## Version 3 catalogue
This build includes 16 original slot prototypes plus Nova Roulette, Nova Blackjack and Nova Orbit (19 catalogue entries). Slot titles share a reusable 5x3 virtual-points prototype engine with distinct original themes. All play is sandbox-only; no cash wagering, deposits or withdrawals.
